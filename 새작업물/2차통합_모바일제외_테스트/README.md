# 2차 통합 테스트 — 모바일 제외 설문

기존 제작 HTML 화면에 팀원의 수정된 설문과 서버 저장을 연결한 Windows 로컬 테스트 패키지입니다.

**압축을 전부 풀고 `2차통합본_실행.bat`을 더블클릭하세요.** Python 3.10 이상이 설치되어 있어야 합니다. 별도 pip 설치나 API 키 입력은 필요 없습니다. 창은 켜두세요.

## 포함된 흐름

- 첫 화면 로그인·회원가입. 설문 미완료 상태에서 회원가입하면 첫 화면을 유지합니다.
- 게이머/비게이머 첫 7문항 → 서버 계산 → 실제 API 추천 → 개인페이지 프로필 자동 생성.
- 개인페이지 → 플레이 성향 → 30문항 진행 → 서버 계산·저장 → 새 프로필 생성 및 자동 활성화.
- 게스트 설문·프로필·찜·최근 조회는 회원가입 시 같은 계정으로 이전합니다.
- 로그아웃·로그인 및 서버 재시작 후 SQLite에서 데이터 복원.
- 프로필 꾸미기(게임 배경, 위치, 어둡기, 아이콘, 닉네임, 소개), 최근 조회·찜 목록.
- AI 생성 설문은 이번 버전에서 진입과 실행을 비활성화했습니다.

첫 7문항 결과와 30문항 결과는 각각 별도 프로필로 보존됩니다. `사용하기`로 선택한 프로필의 가중치가 추천 기준입니다. 아직 두 결과를 합쳐 37문항 점수로 계산하는 방식은 사용하지 않습니다.

## 테스트 순서

1. 첫 화면에서 회원가입하거나 게스트로 시작합니다. 회원가입 시 이메일은 `name@example.com`, 비밀번호는 8~128자입니다.
2. 게임 경험을 선택하고 7문항에 답합니다. API 정보는 실행과 동시에 자동 수집됩니다. 조회된 게임이 있으면 전체 수집 전에도 제출할 수 있으며, 결과에 비교한 게임 수가 표시됩니다.
3. 결과 화면에서 **개인페이지에서 프로필 확인** → **플레이 성향**을 누릅니다. 7문항 프로필과 응답별 가중치를 확인합니다.
4. **30문항 진행**을 누르고 제출합니다. 개인페이지에 30문항 프로필이 추가되며 활성 프로필이 바뀝니다. **프로필 보기**에서 30문항 답변을 확인합니다.
5. **설정 → 백엔드 저장 내용 확인**에서 answers, weights, mapping_audit, recommendation을 확인합니다.
6. 프로필을 꾸미고 게임을 찜한 다음 로그아웃·로그인하여 복원 여부를 확인합니다.
7. 실행 창을 닫고 다시 실행해도 `results` 폴더를 유지하면 계정과 프로필이 유지됩니다.

## 게임 정보와 가중치

- 팀원 설문 원본: 커밋 `1e186d7`, `회원가입_비회원진단_데이터저장개선/data/survey_questions.json`.
- 게이머 7+30, 비게이머 7+30 총 74문항·366선택지를 그대로 사용합니다.
- Steam·IGDB 데이터를 공통 코드로 정규화하며 같은 특징은 중복 점수 처리하지 않습니다.
- 직접 대응 6점, 근접 대응 3점을 기준으로 복수 선택/다중 태그에 나눠 반영합니다. 기피 항목은 음수입니다. 수치는 1차 설계값이며 검증된 추천 정확도 수치가 아닙니다.
- 주간 이용시간, 한 번의 플레이 시간, UI 가독성, 섬광, 과금 압박 등 검증할 API 필드가 없는 항목은 답변을 보관하되 점수에 임의 대입하지 않습니다.
- 모바일 전용 게임과 DLC는 제외합니다. PC·콘솔과 모바일을 함께 지원하는 게임은 유지합니다. 휴대용 PC 선택은 PC 게임 후보로 연결되며 Steam Deck/ROG Ally 호환성 확인을 대신하지 않습니다.
- 추천 후보는 기존 테스트용 AppID **136개**입니다. Steam 전체 게임의 추천 순위가 아닙니다. 부분 수집 중 제출하면 해당 시점에 준비된 게임만 비교합니다.
- [전체 문항별 API 가중치 연결표](문항별_API가중치.md)

## 실행·저장 구조

| 위치 | 역할 |
|---|---|
| frontend/화면_최종.html | 기존 HTML 기반 실제 조작 화면 |
| quick_survey/ | 계정·설문·가중치·개인페이지·API 연결 구현 |
| tests/ | 서버 통합·규칙·데이터 근거 회귀 테스트 |
| results/personal.sqlite3 | 이 실행본의 계정·세션·설문·프로필·활동 저장 |
| results/*.json | 제출 시점의 설문·추천 결과 |
| cache/*.json | Render에서 받은 실제 게임 정보의 1시간 캐시 |

게임 정보는 `https://recomengine-game-api.onrender.com`에서 가져옵니다. 계정은 이 패키지의 로컬 DB에 저장되며 Render나 팀원의 계정 DB와 공유되지 않습니다. 이 패키지를 GitHub에 보관하는 것과 Render에 통합 사이트를 배포하는 것은 별도입니다.

## 검증 및 범위

- 표준 라이브러리 회귀 테스트 6개: 모든 366선택지 검증, 중립/잘못된 응답 차단, 태그 중복 방지, 모바일 전용 제외, 실제 근거만 점수화, HTTP 계정·설문·프로필·활동·재시작 복원.
- 기존 HTML의 DOM 이벤트 통합 테스트: 첫 화면 회원가입 후 화면 유지 → 7문항 → 개인페이지 자동 반영 → 30문항 → 전체 응답 표시 → 로그아웃/재로그인 복원.
- 위 화면 이벤트 검증은 DOM 실행 환경에서 수행했습니다. 이 환경에서는 Chromium 실행이 제한되어 실제 브라우저 렌더링·Windows 더블클릭은 직접 검증하지 못했습니다.
- 추천 데이터는 실제 Render 응답으로 확인했으며 테스트용 가짜 게임 데이터를 실행본에 주입하지 않습니다.
- 이번 완료 범위는 계정·두 고정 설문·개인페이지 연결입니다. 기존 HTML의 뉴스·랭킹·리뷰 등 다른 화면은 이번 통합 검증 대상이 아닙니다.

자동 테스트: `테스트_실행.bat` 또는 `python run_local.py --test`.
