회귀 테스트는 6개이며, 그중 전체 문항 테스트가 366선택지를 순회합니다. DOM 이벤트 검증은 실제 HTML 스크립트와 로컬 Python HTTP 서버를 연결하여 수행했습니다. Chromium 실행 제한으로 픽셀 단위 화면 검사와 Windows 더블클릭은 직접 수행하지 못했습니다.

7문항과 30문항은 각각 보존되는 별도 프로필이며 활성 프로필을 추천에 사용합니다. 37문항 합산 방식이 아닙니다. 추천 후보는 136개 테스트 목록이며 조회 완료 개수에 따라 비교 범위가 달라집니다. 뉴스·랭킹·리뷰 등 기존 다른 화면은 이번 통합 범위에서 제외했습니다.
