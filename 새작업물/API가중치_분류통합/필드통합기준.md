# 분류 및 수치 필드 통합 기준

| 입력 | 공통 결과 | 처리 규칙 |
|---|---|---|
| Steam 장르·사용자 태그 / IGDB genres·themes·keywords | codes + evidence | 명시된 동의어만 병합, 원본 source/id/value 보존 |
| Steam categories / IGDB game_modes | category:* | 싱글·멀티·협동·온라인·로컬을 구분. 같은 코드만 중복 제거 |
| IGDB player_perspectives / Steam 관련 태그 | perspective:* | 시점 분류. 2D/3D 차원과 별도 |
| Steam OS / IGDB platforms | pc·console·mobile + platform_evidence | 확인된 플랫폼만 분류. 미확인 플랫폼은 원본 보존 |
| Steam price_overview | price | 현재가 final/100 + currency. 국가·조회 시점을 수집자가 함께 보관. 통화 간 금액 단순 비교 금지 |
| is_free | price.is_free | 가격 누락을 무료로 취급하지 않음. 무료 플레이 태그와 현재 판매가도 별도 |
| pc/mac/linux_requirements | requirements_by_os | 최소·권장 원문 보존. 고/중/저사양 점수 임의 생성 금지 |
| IGDB game_time_to_beats | completion_hours | hastily/normally/completely 각각 초→시간. count는 유지. 0/누락은 미확인 |
| 한 번의 플레이 시간·주간 이용시간 | session_minutes=null | 클리어 시간과 동일시하지 않음 |
| Steam 리뷰 수 | steam_positive_ratio | positive/(positive+negative), 동일 응답 내 분모 사용. 0건·미제공은 null |
| IGDB rating / total_rating | igdb_user / igdb_total | 사용자 평점·혼합 평점 별도. Steam 긍정 비율과 평균내지 않음 |
| 지원 언어·연령 등급·출시일·패드 지원 | *_raw | 원본 보존, 미수집/미확인 시 null. 한국어 자막·음성 등을 추정하지 않음 |
| 키워드·분류에 신규 값 등장 | unmapped | 원본 ID/문구 유지, review_required. 임의 번역·퍼지 매칭·자동 점수 금지 |
| API 태그의 존재 | 근거 포함 특징 | 태그가 없는 것이 그 특징의 부재를 의미하지는 않음 |
| 멀미·섬광·복잡도·과금 압박 | unknown_fields | 현재 확인한 원본 필드로 객관화할 수 없어 점수화하지 않음 |

## 기존 규칙에서 수정한 경계

- Building ≠ City Builder: 도시 건설은 건설의 하위 개념.
- Turn-Based ≠ Turn-Based Strategy ≠ Turn-Based Combat: 턴제 자체와 하위 유형 분리.
- Top-Down ≠ Isometric ≠ Bird view / Isometric: IGDB의 복합 분류도 원래 범위를 보존.
- Co-op ≠ Online Co-op ≠ Local Co-op: 협동의 접속 방식 보존.
- Farming ≠ Farming Sim, Roguelike ≠ Roguelite.
- FPS와 Shooter는 동의어가 아니라 하위/상위 관계.
- IGDB Card & Board Game, Hack and slash/Beat 'em up 같은 복합 항목을 구성 항목 모두로 확정하지 않음.
- 부모 특징은 parent_codes에 별도로 제공. 기존 추천 점수에 자동 합산하지 않음.

## ID 및 중복 정책

Steam AppID와 IGDB game ID는 다른 식별자입니다. 이 모듈은 이미 AppID로 연결된 기존 Render 응답을 입력으로 받습니다. 게임 이름만으로 두 게임을 연결하지 않습니다.
IGDB 숫자 ID는 endpoint마다 별도 공간입니다. 이름이 펼쳐지지 않은 ID만 받으면 추측하지 않고 미검토 항목으로 남깁니다.
같은 코드가 Steam/IGDB 여러 필드에서 발견돼도 codes에는 1번만 나옵니다. 모든 근거는 evidence에 남습니다.
