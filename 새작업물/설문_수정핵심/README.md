# 첫 설문·개인취향 설문 수정안

[엑셀 수정표 다운로드](./설문_수정핵심.xlsx?raw=true)

첫 7문항만 게이머와 비게이머로 구분하고, 개인페이지에서는 공통 30문항을 사용하는 **수정안**입니다. 실제 설문 코드나 DB에 적용된 상태를 뜻하지 않습니다. 기존 질문 ①은 기존 게이머 경로, ②는 기존 비게이머 경로의 같은 번호입니다.

## 첫 7문항 · 게이머

| 문항 번호 | 수정 전 내용 | 수정내용 |
|---|---|---|
| 1번 | 주로 이용할 수 있는 게임 기기는 무엇인가요?<br>현재: 복수 선택 | 기기별 복수 선택 유지 · ‘PC와 콘솔 모두’ 삭제 |
| 2번 | 한 번 게임을 할 때 어느 정도 시간을 투자하고 싶으신가요?<br>현재: 1개 선택 | 1회 희망 시간 1개 선택 유지 · 동일 질문 생략 |
| 3번 | 게임에서 가장 중요하게 생각하는 재미는 무엇인가요?<br>현재: 최대 2개 | ‘최대 2개 선택’ 명시 |
| 4번 | 다른 사람과 함께하거나 경쟁하는 게임에 대해 어떻게 생각하시나요?<br>현재: 1개 선택 | 복수 선택으로 변경 · 선택값 모두 저장 · ‘상관없음’ 단독 |
| 5번 | 어떤 방식으로 게임을 조작하는 것을 선호하시나요?<br>현재: 1개 선택 | 조작 속도만 질문 · 장치·난이도 분리 |
| 6번 | 게임을 할 때 피하고 싶은 요소는 무엇인가요?<br>현재: 최대 5개 | 회피 요소 최대 5개 유지 · ‘없음’ 단독 |
| 7번 | 어떤 그래픽과 그림체의 게임을 선호하시나요?<br>현재: 최대 2개 | ‘최대 2개 선택’ 명시 · 개인페이지에 답변 반영 |
