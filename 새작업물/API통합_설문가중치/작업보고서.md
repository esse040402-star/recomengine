# 1차 통합 작업 보고서

| 단계 | 확인된 문제 | 처리 | 결과 |
|---|---|---|---|
| GitHub 최신 확인 | main cb09273에 모바일 제외 개정안 없음 | 기존 두 설문 파일 확인, 팀원 개정안과 자체 수정 구분 | 팀원 개정안 대기 |
| 공통 분류 | 한영·대소문자·하이픈·공백 차이 | 명시적 별칭 사전, 출처별 근거 보존 | 적용 |
| 중복 점수 | 같은 특징이 여러 API에 존재 | 코드 집합으로 1회만 매칭 | 자동 검증 통과 |
| 의미 혼동 | 멀티=PvP, 전체 시간=세션 길이 오인 가능 | 서로 다른 필드 유지, 미확정은 null | 적용 |
| 모바일 제외 | 양쪽 7문항에 모바일 선택지 존재 | 선택지 제거, 나머지 ID 유지, 설문 버전 갱신 | 적용 |
| 추천 대상 | 모바일 전용·비게임 혼입 가능 | PC/콘솔 확인된 게임만 추천 | 자동 검증 통과 |
| 가중치 | tag:action과 genre:action 분리 | genre:action으로 통합 | 적용 |
| 근거 없는 분류 | 수동 스냅샷 기반 추천 | normalized 실데이터만 사용, 없으면 data_required | 적용 |
| 세션·사양·불호 | API에 정확한 대응 수치 없음 | 미지원 가중치 명시, 임의 점수 제외 | 남은 데이터 필요 |
| UI 답변→백엔드→저장 | 모바일 제거 후 인덱스 변경 위험 | ID 유지·새 버전 사용, 정의/제출/저장/재조회 테스트 | 통과, 실제 브라우저 클릭 미검증 |
| 회귀 테스트 | 이전 테스트가 선택지 0을 고정 사용 | 반환된 선택지 ID 사용으로 수정 | 7문항 20개 통과 |
| API 테스트 | 새 통합 응답·중복·누락·플랫폼 검증 필요 | 기존 8개 및 신규 6개 검증 | 14개 통과, 테스트 도구 사용 중단 예정 경고 2개 |
| 실데이터 | 레데리2 취향에서도 스타듀밸리 추천 우려 | 동일 답변으로 실제 두 게임 비교 | 레데리2 40점 / 스타듀밸리 25점 |
| 다른 설문 | 기존 온보딩·심층·취향은 별도 체계 | 원본 유지, 추가 적용이 필요함을 문서화 | 미완료·팀원 개정안 확인 후 이어갈 범위 |
| 전체 추천 | 전체 목록과 상세 비교 후보는 다름 | 요청 AppID 내 비교임을 명시 | 전체 게임 상세 수집은 별도 |

코드 테스트 결과는 화면의 미관·추천 품질 전체를 보증하지 않습니다. 가중치 값은 기존 팀 규칙을 유지했으며 이번 작업은 데이터 의미 정합성과 실제 값 연결에 집중했습니다.
