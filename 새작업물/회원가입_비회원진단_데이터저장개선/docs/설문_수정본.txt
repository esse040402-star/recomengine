4. 상황에 따라 달라요.

최대 2개 선택
1. 액션 / 전투: 직접 싸우고 움직이며 느끼는 시원한 재미
2. 전략 / 두뇌: 생각하고 계획을 세워 문제를 해결하는 재미
3. 스토리 / 몰입: 흥미로운 이야기와 세계관에 빠져드는 재미
4. 탐험 / 자유도: 새로운 장소와 숨겨진 요소를 발견하는 재미
5. 성장 / 경영: 캐릭터나 장비를 키우고 무언가를 만들어가는 재미
6. 특별히 선호하는 요소가 없어요.
Q4. 다른 사람과 함께하거나 경쟁하는 게임에 대해 어떻게 생각하시나요?
단일 선택
1. 싱글 플레이: 혼자 내 페이스대로 즐기는 것이 좋아요.
2. 협동 플레이: 다른 사람과 함께 목표를 달성하는 것이 좋아요.
3. 경쟁 플레이: 다른 사람과 실력을 겨루는 것이 좋아요.
4. 상관없어요. 게임에 따라 모두 괜찮아요.
Q5. 어떤 방식으로 게임을 조작하는 것을 선호하시나요?
단일 선택
1. 실시간 조작: 키보드·마우스 또는 컨트롤러로 캐릭터를 직접 움직이는 방식
2. 전략적 조작: 턴제, 카드 선택, 명령 입력 등 생각하며 진행하는 방식
3. 간단한 조작: 마우스 클릭이나 적은 버튼 입력 위주로 편하게 진행하는 방식
4. 조작 방식은 상관없어요.

1. 3D 시점 멀미 및 눈의 피로
2. 과도한 반복 플레이와 파밍
3. 과도한 결제 유도 및 가챠 시스템
4. 지나치게 복잡한 시스템과 퍼즐
5. 다른 사람과의 대전에서 오는 스트레스
6. 특별히 피하고 싶은 요소가 없어요.
Q7. 어떤 그래픽과 그림체의 게임을 선호하시나요?
최대 2개 선택
1. 실사형 3D: 실제 영화나 현실처럼 사실적이고 화려한 그래픽
2. 애니메이션 / 서브컬처: 웹툰이나 애니메이션 같은 그림체
3. 도트 / 픽셀 아트: 레트로하고 아기자기한 그래픽
4. 캐주얼 / 동화풍: 귀엽고 따뜻한 분위기의 그림체
