# 03 통합 업데이트 (2026-11-17)

이 폴더는 `recomengine_update_03.zip`과 `recomengine_update_03_survey_mapping_fixed(1).zip`을 비교해 **새로 추가되거나 내용이 변경된 파일만** 별도로 모은 업데이트 묶음입니다. 전체 프로젝트 복사본이 아니며, 원본 프로젝트의 같은 상대 경로에 적용할 변경분입니다.

## 적용 방법

1. 현재 팀 프로젝트의 백업 또는 별도 작업 복사본을 만듭니다.
2. 이 폴더 안의 `app/`, `frontend/`, `supabase/`, `tests/`, `docs/` 파일을 현재 프로젝트의 같은 상대 경로에 반영합니다.
3. Supabase migration은 파일을 저장소에 올리는 것과 실제 DB에 적용하는 것이 별개입니다. 운영 DB 적용 전 SQL 내용을 검토하고 백업/승인 절차를 따르세요.
4. `.env`, 실제 인증정보, `node_modules`, `.venv`는 포함하지 않았습니다.

## 주요 업데이트

- 설문 선택지 366개 매핑 검토: 점수 축 반영, 명시적 메타데이터, 중립 응답을 구분하고 추천 근거/설명에 반영
- 게이머·비게이머의 목적/숙련/자동 진행/소셜 플레이 선호 반영 및 매핑 테스트 추가
- 비회원 진단 세션을 회원가입·로그인 계정에 연결하는 프론트엔드/백엔드 흐름 보완
- 계정·설문 API 문서 및 mock DB 동작/테스트 보완
- Supabase 설문·특성 데이터 seed 및 권한/세션 연결 관련 migration 추가·갱신

## 비교 결과

- 변경된 파일: 18개
- 새로 추가된 파일: 15개
- 삭제 파일은 팀 저장소의 기존 파일을 보호하기 위해 이 업데이트 묶음에서 삭제하지 않았습니다.
- 압축본에 포함된 캐시, 바이트코드, 가상환경, node_modules 및 깨진 파일명으로 판별되는 문서는 제외했습니다.

## 검증 상태

- 프론트엔드 Node 테스트: 14개 통과
- 백엔드 pytest: 102개 통과
- 사용자의 Windows PC에서 `npm.cmd ci` 및 `npm.cmd run build` 성공 확인
- 사용자가 게이머/비게이머 설문 추천과 소셜/장르/난이도/플레이 목적 선택 변경에 따른 추천 결과 변화를 확인
- 실제 운영 Supabase/Render 전체 통합 검증을 완료했다는 의미는 아닙니다.

세부 설문 매핑 검토는 `docs/survey_mapping_review_20261117.md`, Supabase 운영 변경 기록은 `docs/supabase_2026-11-17_live_update.md`를 참고하세요.
